# 第14回　母平均の差の検定

検定の手順と種類（1標本・2標本、対応の有無、パラメトリック／ノンパラメトリック）、両側検定と片側検定、p値を整理したうえで、2標本の母平均の差・母分散の差（F検定）・母比率の差の検定を例題で解説し、効果量やRでの検定関数、カイ2乗検定の演習を扱います。2025年度は主成分分析（考え方、固有値分解、寄与率、バイプロット、Rでの実行）の補足スライドも用意されています。
