## この授業について

記述統計から推測統計まで、統計学の基礎を14回で学ぶ大学院（法学研究科）向けの授業です。1変数・2変数データの要約から始めて、確率変数、母集団と標本、区間推定、仮説検定へと進みます。あわせて、RやPython（Google Colab）を使ったデータ分析の基本操作も身につけます。

| | |
|---|---|
| **大学** | 立教大学 |
| **開講** | 大学院法学研究科（科目コード ND363） ／ 春学期 |
| **担当年度** | 2023〜2025年度 |
| **使用ツール** | R、Python（Google Colab）、R（Google Colab） |

第1回・第2回・第14回のみ対面で、第3〜13回は解説動画を視聴するオンデマンド形式でした。対面回はスライドを、オンデマンド回は解説動画（YouTube）と課題（第3・7・11回に出題）を掲載しています。
